# יופי של ציפורניים - אתר הזמנת תורים

אתר הזמנת תורים למעצבת ציפורניים המאפשר ללקוחות להזמין תורים ולעסקים לנהל את התורים שלהם.

## תכונות עיקריות

### עבור לקוחות:
- **הזמנת תורים**: בחירת שירות, תאריך ושעה
- **לוח זמנים דינמי**: הצגת זמנים זמינים בלבד
- **ניהול התנגשויות**: אזהרה על התנגשויות עם אפשרות להמשיך לרשימת המתנה
- **הערות ודירוג**: אפשרות להוסיף הערות ודירוג כוכבים
- **התחברות**: התחברות באמצעות מספר טלפון ואימות WhatsApp
- **ניהול תורים**: צפייה בתורים מאושרים וממתינים לאישור
- **ביטול תורים**: אפשרות לבטל תורים

### עבור עסקים:
- **הרשמת עסק**: טופס הרשמה מלא עם פרטי עסק, שעות פעילות ושירותים
- **התחברות**: התחברות באמצעות אימייל/טלפון וסיסמה עם אימות אימייל
- **ניהול תורים**: צפייה באישור וביטול תורים
- **ניהול שירותים**: עריכת שירותים והוספת תמונות
- **עריכת פרטי עסק**: עדכון פרטים לא קריטיים
- **מחיקת עסק**: אפשרות למחוק את העסק מהמערכת

## טכנולוגיות

- **React 18** עם TypeScript
- **React Router** לניווט
- **date-fns** לטיפול בתאריכים
- **CSS3** עם תמיכה ב-RTL לעברית
- **Responsive Design** לעבודה על כל המכשירים

## התקנה והפעלה

1. **התקנת תלויות**:
   ```bash
   npm install
   ```

2. **הפעלת השרת**:
   ```bash
   npm start
   ```

3. **גישה לאתר**:
   פתח את הדפדפן בכתובת: `http://localhost:3000`
